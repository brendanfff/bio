# brendanff — bio

Personal bio / link-in-bio page, deployed at [brendanff.github.io/bio](https://brendanff.github.io/bio).

## Tech Stack

- React 19 + Vite
- Tailwind CSS v4
- [motion](https://motion.dev/)
- [react-icons](https://react-icons.github.io/react-icons/)

## Run Locally

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Deploy

Push to `main` → GitHub Actions auto-builds and deploys to Pages.
